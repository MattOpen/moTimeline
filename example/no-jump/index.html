Columns before the script

The list carries mo-timeline mo-early mo-gap and --mo-twocol-min: 600px in the HTML. The script loads only after ms, yet the cards stand in their columns from the first paint: one column while the list is narrower than 600 px, two from 600 px on. After the start the script only moves cards into the shorter column; their width stays (motimeline-947).

before the script…

  • Kick-off

    Scope agreed, first sketches on the table.

  • Research

    Twelve interviews with users of the old tool. Most of them asked for the same three things: speed, a cleaner list and fewer clicks to the detail view.

  • Prototype

    Clickable prototype in two days.

  • Review

    Feedback round with the team, a second with two customers.

  • Build

    Library mode, ESM, CJS and UMD bundles. Tests for the layout in four widths, then the first public release with a demo page and a changelog.

  • Launch

    Release notes out.
